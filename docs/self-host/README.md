# Self-host

Run your own Schuly server, so your school data stays on hardware you control. The server includes
the API and the web app. You need a Linux server with Docker and some experience running one.

## Choose your setup

| You want to | Start here |
|---|---|
| Run Schuly on a server with a domain and HTTPS | [Self-host Schuly](/SchulyServer/setup/self-hosting) |
| Test Schuly on your local network | [Run without a domain](/SchulyServer/setup/self-hosting-lan) |

## Once it's running

- [Run and upgrade your server](/SchulyServer/setup/operations): backups, upgrades, and data retention
- [Plugin management](/SchulyServer/plugin-management): choose which school systems your server offers
- [Configuration](/SchulyServer/setup/configuration): all settings
