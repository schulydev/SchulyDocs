# Selbst hosten

Betreibe deinen eigenen Schuly-Server, damit deine Schuldaten auf Hardware bleiben, die du
kontrollierst. Der Server enthält die API und die Web-App. Du brauchst einen Linux-Server mit Docker
und etwas Erfahrung im Serverbetrieb.

## Setup wählen

| Du willst | Starte hier |
|---|---|
| Schuly auf einem Server mit Domain und HTTPS betreiben | [Schuly selbst hosten](/de/SchulyServer/setup/self-hosting) |
| Schuly in deinem lokalen Netzwerk testen | [Ohne Domain betreiben](/de/SchulyServer/setup/self-hosting-lan) |
