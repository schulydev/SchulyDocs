# 1. App installieren

Schuly ist noch nicht im App Store oder bei Google Play. Wähle, wie du es nutzen willst:

| Gerät | So bekommst du Schuly |
|---|---|
| Android | Lade die `.apk` von den [GitHub Releases](https://github.com/schulydev/Schuly/releases) herunter und öffne sie. Android fragt dich beim ersten Mal, ob du Installationen aus deinem Browser erlaubst. |
| iPhone oder iPad | Lade die `.ipa` von den [GitHub Releases](https://github.com/schulydev/Schuly/releases) herunter und installiere sie per Sideloading. |
| Browser | Öffne [app.schuly.dev](https://app.schuly.dev). Du musst nichts installieren und brauchst ein Schuly-Konto. |

Installiere **Schuly**, nicht **Schuly DEV**. Die DEV-Version ist ein Testbuild für Mitwirkende.

## Updates

Schuly sucht nach neuen Versionen und bietet sie in der App an. Auf Android kannst du ein Update
direkt installieren. Auf iPhone und iPad verlinkt Schuly das neue Release.
