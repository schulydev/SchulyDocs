# 1. App installieren

Schuly läuft auf **Android** und **iOS**.

- **Hol sie dir auf [schuly.dev](https://schuly.dev)** - die Website verlinkt immer die
  neuesten Builds für jede Plattform.
- **Android** - installiere sie aus dem Store-Eintrag, oder lade die `.apk`-Datei direkt
  von den [GitHub Releases](https://github.com/schulydev/Schuly/releases) herunter
  (Sideloading). Dabei fragt Android dich beim ersten Mal, ob du Installationen aus
  deinem Browser bzw. deiner Dateien-App erlauben willst.
- **iOS** - installiere sie aus dem auf der Website verlinkten Store-Eintrag.

:::info Zwei Varianten
Du siehst vielleicht **Schuly** und **Schuly DEV**. Installiere **Schuly** - "DEV" ist
ein separater Testbuild für Mitwirkende und kann parallel laufen, ohne deine echten
Daten zu beeinflussen.
:::

Sobald die App installiert ist, öffne sie und geh weiter zu
**[Anmeldeart wählen](choose-a-mode.md)**.
