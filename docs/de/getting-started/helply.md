# Helply fragen

Helply ist ein KI-Assistent in der Schuly-Web-App. Er beantwortet Fragen zu deinen Schuldaten,
zum Beispiel «Welche Prüfungen habe ich diese Woche?». Du brauchst dafür ein Schuly-Konto.

Helply ist nicht auf jedem Server verfügbar. Ist es ausgeschaltet, hat der Server es nicht eingerichtet.

::: warning Deine Daten gehen an einen KI-Dienst
Um dir zu antworten, sendet Helply deine Nachrichten, deine Anhänge und die gelesenen Daten an den
KI-Dienst, den dein Server nutzt. KI-Antworten können falsch sein. Prüfe deshalb alles Wichtige.
:::

## Chat starten

1. Öffne [app.schuly.dev](https://app.schuly.dev) und melde dich an.
2. Wähle in der Seitenleiste unter **AI** den Eintrag **Helply**.
3. Tippe eine Frage ein und drücke Enter. Für eine neue Zeile drücke Shift+Enter.

Um Dateien anzuhängen, ziehe sie in den Chat. Du kannst pro Nachricht bis zu 5 Dateien anhängen, jede
bis zu 20 MB gross.

## Wählen, was Helply nutzen darf

Öffne **Helply settings** und lege für jeden Bereich fest, was Helply lesen oder ändern darf, zum
Beispiel bei Noten oder E-Mails. Deine Änderungen gelten ab deiner nächsten Nachricht.

## Änderungen bestätigen

Helply fragt nach, bevor es etwas tut, das deine Daten ändert, zum Beispiel eine E-Mail löschen. Wähle
**Approve** oder **Deny**.

## Code auf deinen Dateien ausführen

Wenn dein Server das anbietet, schalte in **Helply settings** die Option **Workspace (run code)** ein.
Helply kann dann Code auf deinen Anhängen ausführen, zum Beispiel um ein Diagramm deiner Noten zu
erstellen. Der Workspace hat keinen Internetzugang.

## Wie lange Chats gespeichert bleiben

Schuly löscht Unterhaltungen nach 30 Tagen automatisch, zusammen mit ihren Anhängen. Du kannst sie
auch jederzeit selbst löschen.
