# 2. Anmeldeart wählen

Beim ersten Start fragt dich Schuly, wie du die App nutzen möchtest. Es gibt zwei Modi -
du kannst deine Meinung später noch ändern, also mach dir jetzt nicht zu viele Gedanken.

:::info Self-Hosting? Wähle zuerst deinen Server
Kurz vor der Moduswahl fragt dich Schuly, **welchen Server** du nutzen willst. Fast alle
sollten bei **Schuly Cloud** (Standard) bleiben. Falls du dein eigenes Schuly-Backend
betreibst, wähle **Self-hosted** und gib dessen URL ein - Schuly prüft, ob sie erreichbar
ist (und zeigt die Version an), bevor es weitergeht. Beide Modi unten sprechen dann mit
dem Server, den du gewählt hast.
:::

## Konto-Modus (für die meisten empfohlen)

Du meldest dich mit einem **Schuly-Konto** an. Deine Daten werden im Hintergrund
synchronisiert und aktuell gehalten, damit die App schnell öffnet und auf allen Geräten
auf dem neusten Stand ist.

- Am einfachsten, und die App aktualisiert deine Daten von selbst.
- Gleiche Daten auf jedem Gerät, auf dem du dich anmeldest.
- Deine Schuldaten werden auf dem Schuly-Backend gespeichert, damit sie synchronisiert
  werden können.

## Privater / sicherer Modus (datenschutzorientiert)

**Kein Schuly-Konto, kein Schuly-Login.** Du verbindest dich direkt mit deinem
Schulsystem, und deine Zugangsdaten bleiben **nur auf deinem Gerät**. Schuly ruft deine
Daten live ab und speichert **nichts** auf seinen Servern.

- Maximale Privatsphäre - nichts von deinen Schuldaten liegt auf Schulys Servern.
- Funktioniert trotzdem mit denselben Schulen.
- Die Daten werden live abgerufen, sie laden also beim Öffnen der App, statt im
  Hintergrund zu synchronisieren.

## Was soll ich wählen?

| Du willst…                                            | Wähle               |
| ------------------------------------------------------ | ------------------- |
| Die einfachste Einrichtung und Updates im Hintergrund   | **Konto-Modus**     |
| Alles auf dem Gerät behalten, nichts gespeichert        | **Privater Modus**  |
