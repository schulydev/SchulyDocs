# 2. Anmeldeart wählen

Beim ersten Öffnen stellt dir Schuly zwei Fragen. Du kannst deine Antworten später ändern.

## Welcher Server?

Wähle **Schuly Cloud**, den offiziellen Server, ausser du betreibst deinen eigenen. In dem Fall
wähle **Self-hosted** und gib dessen **Backend URL** ein. Wie du einen eigenen Server betreibst,
steht unter [Schuly selbst hosten](/de/self-host/).

## Schuly-Konto oder privater Modus?

| | Schuly-Konto | Privater Modus |
|---|---|---|
| Anmeldung mit | Einem Schuly-Konto | Nur deinem Schul-Login |
| Datenaktualisierung | Im Hintergrund | Beim Öffnen der App |
| Benachrichtigungen über neue Noten | Ja | Nein |
| Gleiche Daten auf all deinen Geräten | Ja | Nein |
| Deine Schuldaten | Auf dem Server gespeichert | Nur auf deinem Telefon gespeichert |
| Dein Schul-Login | Verschlüsselt auf dem Server oder nur eine Sitzung, je nach Schule | Nur auf deinem Telefon gespeichert |

Wähle **Schuly account**, wenn Schuly aktuell bleiben soll, ohne dass du es öffnest. Das wählen die
meisten.

Wähle **Private mode**, wenn du deine Daten nicht auf einem Server speichern willst. Dein Login läuft
trotzdem jedes Mal über den Schuly-Server, wenn Schuly deine Daten lädt. Der Server speichert ihn
aber nicht.
