# SchulyWebsite-Dokumentation

Die Angular-20-Marketingseite für [schuly.dev](https://schuly.dev). Es handelt sich um
eine Angular-App mit Standalone-Komponenten, die mit **Bun** als Paketmanager gebaut
und gepackt sowie auf **Cloudflare Pages** deployt wird.

## Inhalt

- [Setup - Entwicklung](setup/development.md) - lokale Umgebung, Voraussetzungen, Dev-/Build-Befehle.
- [Setup - Deployment](setup/deployment.md) - Cloudflare-Pages-Konfiguration, Build-Ausgabe, PR-Preview-Deploys.
- [Setup - Release](setup/release.md) - wie Versionen geschnitten und synchronisiert werden.
- [Architektur](architecture.md) - Stack-Übersicht und Angular-20-Coding-Konventionen.
- [Contributing](contributing.md) - der verbindliche Workflow aus Issue → Branch → PR → Squash-Merge.
