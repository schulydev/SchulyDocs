# SchulyWebsite-Dokumentation

Nutze diese Seiten, um die Marketing-Site unter [schuly.dev](https://schuly.dev) auszuführen, zu ändern und auszuliefern. Sie
ist eine Angular-20-App mit Standalone Components. Sie nutzt Bun als Package Manager und wird auf Cloudflare Pages deployt.
