# 1. Install the app

Schuly isn't in the App Store or Google Play yet. Choose how you want to use it:

| Device | How to get Schuly |
|---|---|
| Android | Download the `.apk` from [GitHub releases](https://github.com/schulydev/Schuly/releases) and open it. Android asks you to allow installs from your browser the first time. |
| iPhone or iPad | Download the `.ipa` from [GitHub releases](https://github.com/schulydev/Schuly/releases) and sideload it. |
| Browser | Open [app.schuly.dev](https://app.schuly.dev). There's nothing to install, and you need a Schuly account. |

Install **Schuly**, not **Schuly DEV**. The DEV version is a test build for contributors.

## Updates

Schuly checks for new versions and offers them in the app. On Android, you can install an update
directly. On iPhone and iPad, Schuly links to the new release.
