# Chiedi a Helply

Helply è un assistente IA nell'app web di Schuly. Può rispondere a domande sui tuoi dati scolastici,
come "Quali esami ho questa settimana?". Ti serve un account Schuly.

Helply non è disponibile su tutti i server. Se è disattivato, il server non l'ha configurato.

::: warning I tuoi dati vanno a un servizio di IA
Per risponderti, Helply invia i tuoi messaggi, i tuoi allegati e i dati che legge al servizio di IA
usato dal tuo server. Le risposte dell'IA possono essere sbagliate, quindi controlla tutto ciò che è importante.
:::

## Inizia una chat

1. Apri [app.schuly.dev](https://app.schuly.dev) e accedi.
2. Nella barra laterale, sotto **AI**, scegli **Helply**.
3. Scrivi una domanda e premi Invio. Per andare a capo, premi Maiusc+Invio.

Per allegare file, trascinali nella chat. Puoi allegare fino a 5 file per messaggio, ognuno fino a 20 MB.

## Scegli cosa può usare Helply

Apri **Helply settings** per impostare cosa Helply può leggere o modificare per ogni area, come le note o la posta.
Le tue modifiche valgono dal messaggio successivo.

## Approva le modifiche

Helply chiede conferma prima di fare qualsiasi cosa che modifica i tuoi dati, come eliminare una mail. Scegli
**Approve** o **Deny**.

## Esegui codice sui tuoi file

Se il tuo server lo offre, attiva **Workspace (run code)** in **Helply settings**. Helply può quindi
eseguire codice sui tuoi allegati, ad esempio per creare un grafico delle tue note. Il workspace non ha
accesso a internet.

## Per quanto tempo vengono conservate le chat

Schuly elimina automaticamente le conversazioni dopo 30 giorni, insieme ai loro allegati. Puoi anche
eliminarle tu in qualsiasi momento.
