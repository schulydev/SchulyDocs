# 1. Installa l'app

Schuly non è ancora nell'App Store né su Google Play. Scegli come vuoi usarla:

| Dispositivo | Come ottenere Schuly |
|---|---|
| Android | Scarica il file `.apk` dalle [release su GitHub](https://github.com/schulydev/Schuly/releases) e aprilo. La prima volta Android ti chiede di consentire le installazioni dal tuo browser. |
| iPhone o iPad | Scarica il file `.ipa` dalle [release su GitHub](https://github.com/schulydev/Schuly/releases) e installalo in sideload. |
| Browser | Apri [app.schuly.dev](https://app.schuly.dev). Non devi installare nulla e ti serve un account Schuly. |

Installa **Schuly**, non **Schuly DEV**. La versione DEV è una build di test per chi contribuisce.

## Aggiornamenti

Schuly cerca nuove versioni e te le propone nell'app. Su Android puoi installare un aggiornamento
direttamente. Su iPhone e iPad, Schuly rimanda alla nuova release.
