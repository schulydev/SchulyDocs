# 1. Installa l'app

Schuly funziona su **Android** e **iOS**.

- **Scaricala da [schuly.dev](https://schuly.dev)** - il sito rimanda sempre alle
  versioni più recenti per ogni piattaforma.
- **Android** - installala dalla scheda dello store, oppure carica manualmente il file
  `.apk` pubblicato nelle [release su GitHub](https://github.com/schulydev/Schuly/releases).
  Se lo carichi manualmente, la prima volta Android ti chiederà di autorizzare le
  installazioni dal tuo browser o dalla tua app file.
- **iOS** - installala dalla scheda dello store collegata sul sito.

:::info Due versioni
Potresti vedere **Schuly** e **Schuly DEV**. Installa **Schuly** - "DEV" è una versione
di test separata usata dai contributori e può funzionare in parallelo senza toccare i
tuoi dati reali.
:::

Una volta installata, aprila e passa a
**[scegliere come accedere](choose-a-mode.md)**.
