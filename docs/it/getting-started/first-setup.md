# 3. Collega la tua scuola

## Con un account Schuly

1. Accedi, oppure scegli di registrarti. Per registrarti, inserisci un nome utente, un indirizzo
   email e una password di almeno 8 caratteri.
2. Conferma il tuo indirizzo email con il link nella mail che ricevi.
3. Scegli il tuo sistema scolastico dall'elenco.
4. Accedi con il tuo login scolastico.

Schuly poi sincronizza i tuoi dati in background.

## In modalità privata

1. Scegli il tuo sistema scolastico dall'elenco.
2. Inserisci i dati di accesso richiesti dalla tua scuola.

Schuly salva il tuo login nella memoria sicura del tuo telefono. Quando la tua scuola ti disconnette,
Schuly ti riconnette automaticamente.

## Non vedi il tuo sistema scolastico?

Schuly funziona con Schulnetz e OdA Org. Per chiedere un altro sistema,
[apri un issue su GitHub](https://github.com/schulydev/Schuly/issues).
