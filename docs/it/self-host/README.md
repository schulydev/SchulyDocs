# Self-hosting

Esegui il tuo server Schuly, così i tuoi dati scolastici restano su hardware che controlli tu. Il
server include l'API e l'app web. Ti servono un server Linux con Docker e un po' di esperienza nella
sua gestione.

## Scegli la tua configurazione

| Vuoi | Inizia da qui |
|---|---|
| Eseguire Schuly su un server con dominio e HTTPS | [Self-hosting di Schuly](/it/SchulyServer/setup/self-hosting) |
| Testare Schuly sulla tua rete locale | [Eseguire senza dominio](/it/SchulyServer/setup/self-hosting-lan) |
