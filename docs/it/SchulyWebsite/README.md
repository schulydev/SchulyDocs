# Documentazione di SchulyWebsite

Usa queste pagine per eseguire, modificare e rilasciare il sito di marketing su [schuly.dev](https://schuly.dev). È
un'app Angular 20 con componenti standalone. Usa Bun come gestore di pacchetti e viene distribuita su
Cloudflare Pages.
