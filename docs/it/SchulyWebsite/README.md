# Documentazione di SchulyWebsite

Il sito vetrina Angular 20 di [schuly.dev](https://schuly.dev). È un'app Angular a
componenti standalone, costruita e impacchettata con **Bun** come gestore di
pacchetti, e distribuita su **Cloudflare Pages**.

## Contenuti

- [Setup - Sviluppo](setup/development.md) - ambiente locale, prerequisiti, comandi dev/build.
- [Setup - Distribuzione](setup/deployment.md) - configurazione Cloudflare Pages, output del build, deploy di anteprima delle PR.
- [Setup - Release](setup/release.md) - come vengono create e sincronizzate le versioni.
- [Architettura](architecture.md) - panoramica dello stack e convenzioni di codice Angular 20.
- [Contributing](contributing.md) - il workflow obbligatorio issue → branch → PR → squash-merge.
