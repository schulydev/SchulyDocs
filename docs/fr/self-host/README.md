# Auto-héberger

Fais tourner ton propre serveur Schuly, pour que tes données scolaires restent sur du matériel que
tu contrôles. Le serveur comprend l'API et l'application web. Il te faut un serveur Linux avec Docker
et un peu d'expérience pour en faire tourner un.

## Choisir ta configuration

| Tu veux | Commence ici |
|---|---|
| Faire tourner Schuly sur un serveur avec un domaine et HTTPS | [Auto-héberger Schuly](/fr/SchulyServer/setup/self-hosting) |
| Tester Schuly sur ton réseau local | [Faire tourner Schuly sans domaine](/fr/SchulyServer/setup/self-hosting-lan) |
