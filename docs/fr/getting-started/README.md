# Bien démarrer avec Schuly

Schuly affiche tes notes, examens, horaire, absences et documents de ton portail scolaire dans une
seule application. Il est gratuit et open source, et fonctionne avec Schulnetz et OdA Org.

Schuly est un projet indépendant. Ce n'est pas une application officielle de ton école, de Schulnetz
ou d'OdA Org.

## Configurer Schuly

1. [Installer l'application](install.md)
2. [Choisir comment te connecter](choose-a-mode.md)
3. [Connecter ton école](first-setup.md)
4. [Explorer tes données](using-schuly.md)

Tu ne sais pas quoi choisir ? Utilise **Schuly Cloud** et un **Schuly account**. Tu pourras changer
d'avis plus tard.

## En option

- [Configurer les codes à deux facteurs](authenticator.md) dans Schuly, pour ne pas avoir besoin d'une application d'authentification séparée.
- [Demander à Helply](helply.md), l'assistant IA de l'application web.
- [Connecter une application d'IA](connect-ai-apps.md), comme Claude ou ChatGPT, à tes données scolaires.
