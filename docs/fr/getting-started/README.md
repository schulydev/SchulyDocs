# Bien démarrer avec Schuly

Nouveau sur Schuly ? Ce guide t'accompagne de l'installation jusqu'à la consultation de
tes premières notes, en quelques minutes.

**Schuly** est une application mobile qui réunit tes données scolaires - notes, examens,
horaire et absences - provenant des systèmes scolaires basés sur Schulnetz, au même
endroit.

## Le guide

1. **[Installer l'application](install.md)** - obtenir Schuly sur Android ou iOS.
2. **[Choisir ton mode de connexion](choose-a-mode.md)** - mode Compte ou mode Privé.
3. **[Connecter ton école](first-setup.md)** - choisir ton système scolaire et te
   connecter.
4. **[Explorer tes données](using-schuly.md)** - notes, examens, horaire, absences.

Une fois configuré, Schuly peut aussi **[gérer tes codes à deux
facteurs](authenticator.md)**, pour que tu n'aies pas besoin d'une application
d'authentification séparée.

:::tip Pressé ?
La plupart des gens : installer Schuly → choisir le **mode Compte** → sélectionner son
école → se connecter → terminé. Les pages ci-dessus ne comptent vraiment que si tu veux
l'option axée sur la confidentialité, ou si tu rencontres un problème.
:::
