# Demander à Helply

Helply est un assistant IA dans l'application web Schuly. Il peut répondre à des questions sur tes
données scolaires, comme « Quels examens ai-je cette semaine ? ». Il te faut un compte Schuly.

Helply n'est pas disponible sur tous les serveurs. S'il est désactivé, le serveur ne l'a pas configuré.

::: warning Tes données vont à un service d'IA
Pour te répondre, Helply envoie tes messages, tes pièces jointes et les données qu'il lit au service
d'IA que ton serveur utilise. Les réponses d'une IA peuvent être fausses, donc vérifie tout ce qui est
important.
:::

## Démarrer une discussion

1. Ouvre [app.schuly.dev](https://app.schuly.dev) et connecte-toi.
2. Dans la barre latérale, sous **AI**, choisis **Helply**.
3. Écris une question et appuie sur Entrée. Pour commencer une nouvelle ligne, appuie sur Maj+Entrée.

Pour joindre des fichiers, fais-les glisser dans la discussion. Tu peux joindre jusqu'à 5 fichiers par
message, de 20 Mo au maximum chacun.

## Choisir ce que Helply peut utiliser

Ouvre **Helply settings** pour définir ce que Helply peut lire ou modifier dans chaque domaine, comme
les notes ou les mails. Tes changements s'appliquent à ton prochain message.

## Approuver les modifications

Helply demande ton accord avant toute action qui modifie tes données, comme la suppression d'un mail.
Choisis **Approve** ou **Deny**.

## Exécuter du code sur tes fichiers

Si ton serveur le propose, active **Workspace (run code)** dans **Helply settings**. Helply peut alors
exécuter du code sur tes pièces jointes, par exemple pour faire un graphique de tes notes. Le workspace
n'a pas d'accès à Internet.

## Durée de conservation des discussions

Schuly supprime automatiquement les conversations après 30 jours, avec leurs pièces jointes. Tu peux
aussi les supprimer toi-même à tout moment.
