# 2. Choisir comment te connecter

Au premier lancement, Schuly pose deux questions. Tu pourras changer tes réponses plus tard.

## Quel serveur ?

Choisis **Schuly Cloud**, le serveur officiel, sauf si tu fais tourner le tien. Dans ce cas, choisis
**Self-hosted** et saisis son adresse dans **Backend URL**. Pour faire tourner ton propre serveur, voir
[Auto-héberger Schuly](/fr/self-host/).

## Compte Schuly ou mode Privé ?

| | Compte Schuly | Mode Privé |
|---|---|---|
| Connexion avec | Un compte Schuly | Tes identifiants scolaires uniquement |
| Mise à jour des données | En arrière-plan | À l'ouverture de l'application |
| Notifications de nouvelles notes | Oui | Non |
| Mêmes données sur tous tes appareils | Oui | Non |
| Tes données scolaires | Stockées sur le serveur | Stockées uniquement sur ton téléphone |
| Tes identifiants scolaires | Chiffrés sur le serveur, ou seulement une session, selon ton école | Stockés uniquement sur ton téléphone |

Choisis **Schuly account** si tu veux que Schuly reste à jour sans que tu l'ouvres. La plupart des
gens choisissent cette option.

Choisis **Private mode** si tu ne veux pas que tes données soient stockées sur un serveur. Tes
identifiants passent quand même par le serveur Schuly chaque fois que Schuly charge tes données, mais
le serveur ne les stocke pas.
