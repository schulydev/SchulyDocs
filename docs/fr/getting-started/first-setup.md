# 3. Connecter ton école

Schuly n'est pas livré avec une liste fixe d'écoles. La liste actuelle se charge dès que
tu arrives sur cet écran - il te suffit donc de choisir la tienne, rien à saisir ni à
configurer manuellement.

## Étape 1 - Choisir ton système scolaire

Choisis ton école / ton système dans la liste que Schuly t'affiche. Cette liste est
chargée en direct, de nouvelles écoles peuvent donc apparaître sans mise à jour de
l'application.

## Étape 2 - Se connecter

Ce qui suit dépend du mode que tu as choisi :

### Si tu as choisi le mode Compte

Tu seras dirigé vers la **connexion Schuly**. Nouveau ici ? L'application t'emmène
directement vers l'inscription, et créer un compte est rapide - juste un **nom
d'utilisateur, une adresse e-mail et un mot de passe** (pas de champs pour ton nom).
Connecte-toi (ou inscris-toi), et voilà - Schuly relie ton école à ton compte et garde
tes données synchronisées.

### Si tu as choisi le mode Privé

Schuly affiche un **écran de connexion avec les champs requis par ton école** (par
exemple un nom d'utilisateur/e-mail et un mot de passe, ainsi qu'un code à usage unique
si ton école utilise l'authentification à deux facteurs). Les champs exacts sont
fournis par ton système scolaire, tu ne vois donc que ce qui est pertinent.

- Tes identifiants scolaires sont enregistrés **uniquement dans le stockage sécurisé de
  ton téléphone** - ils ne sont jamais envoyés à Schuly ni stockés sur ses serveurs.
- Si ton école demande un code à usage unique, Schuly peut le générer sur ton téléphone
  depuis l'écran **Authenticator** après la configuration.
- Quand ton école te déconnecte, Schuly se reconnecte discrètement avec les
  identifiants enregistrés sur ton téléphone, pour que tu restes connecté.

:::tip Changer d'école ou de mode plus tard
Tu peux connecter une autre école, ou basculer entre le mode Compte et le mode Privé,
depuis les paramètres de l'application à tout moment.
:::

Connecté ? Il est temps d'**[explorer tes données](using-schuly.md)**.
