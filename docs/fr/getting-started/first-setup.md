# 3. Connecter ton école

## Avec un compte Schuly

1. Connecte-toi, ou choisis de t'inscrire. Pour t'inscrire, saisis un nom d'utilisateur, une adresse
   e-mail et un mot de passe d'au moins 8 caractères.
2. Confirme ton adresse e-mail avec le lien dans le mail que tu reçois.
3. Choisis ton système scolaire dans la liste.
4. Connecte-toi avec tes identifiants scolaires.

Schuly synchronise ensuite tes données en arrière-plan.

## En mode Privé

1. Choisis ton système scolaire dans la liste.
2. Saisis les identifiants que ton école demande.

Schuly enregistre tes identifiants dans le stockage sécurisé de ton téléphone. Quand ton école te
déconnecte, Schuly te reconnecte automatiquement.

## Tu ne vois pas ton système scolaire ?

Schuly fonctionne avec Schulnetz et OdA Org. Pour demander un autre système,
[ouvre une issue sur GitHub](https://github.com/schulydev/Schuly/issues).
